GlacierAI V2.8 更新说明
========================

发布日期：2026-05-26

新增功能
--------

1. 界面字体大小可调
   - 范围 80% – 140%，5% 步进，默认 100%
   - 通过设置面板的滑条调节，效果作用于全局所有控件

2. 界面亮度可调
   - 范围 -20 – +40，5 步进，默认 0
   - 拖拽时整体偏移背景与前景色，可在偏暗或偏亮的环境下找到合适观感
   - 不切换主题色，保持原有的深色风格

3. 设置入口
   - 左侧导航底部新增 "⚙ 设置" 按钮
   - 拖动滑条可即时预览效果
   - "应用"按钮保存设置；关闭对话框则回滚到打开前的状态
   - "恢复默认" 一键回到 100% / 0

4. 配置持久化
   - 设置保存在 exe 同目录下的 ui_settings.json
   - 下次启动自动应用


使用说明
--------

- 点击左侧导航底部 "⚙ 设置" 打开设置面板
- 拖动滑条即可看到字体或亮度的实时变化
- 调到合适后点 "应用" 保存；不满意可点 "恢复默认" 或直接关闭对话框
- 字体设置同时影响输入框、按钮、菜单等所有界面元素
- 亮度只影响主界面，登录页保持原色


范围说明
--------

字体大小
  80%  ：紧凑，适合小屏笔记本
  100% ：默认
  120% ：较大
  140% ：最大，适合高分辨率屏或视力疲劳时

界面亮度
  -20  ：更暗（深色环境）
  0    ：默认
  +20  ：偏亮
  +40  ：最亮（亮色环境）


文件改动
--------

- app.py
  - 新增 import：QSlider、re
  - 新增常量 UI_SETTINGS_JSON、DEFAULT_UI_SETTINGS
  - 新增工具函数：load_ui_settings / save_ui_settings、apply_ui_adjustments、shift_inline_bg
  - 新增 SettingsDialog 类与配套 QSS（SETTINGS_DIALOG_STYLE）
  - MainWindow 新增 _font_scale / _brightness 字段，新增 _apply_ui_settings / _open_settings 方法
  - 左侧导航新增 nav_settings_btn 按钮
  - central widget 与三个内容页背景登记到 _bg_pages，亮度调节时一起刷新


兼容性
------

- 历史记录、API Key 缓存等数据格式均无变化，可平滑覆盖升级
- 首次启动若未生成 ui_settings.json，按默认值 100% / 0 加载
- 若 ui_settings.json 损坏或解析失败，自动回退到默认值
